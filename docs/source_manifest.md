# Source manifest and lawful provenance

This challenge implementation uses entirely synthetic candidate names, contact addresses under the reserved `example.test` domain, locations, skills, experience, interview records and offer records. No real candidate resumes or personal data are imported. ResumeArtifact rows are metadata placeholders with deterministic SHA-256 content hashes; no actual resume files are represented.

External datasets are not required. If public reference data is added later, record its URL, dataset/version, retrieval date, license/terms, attribution, transformations and discarded fields here before redistribution.
